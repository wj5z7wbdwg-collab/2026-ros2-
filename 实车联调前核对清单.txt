## 第 4 关：物理测量标定（顺序不可颠倒）

回填位置：autocar_ws/src/*/config/*.yaml；或启动时用 <参数>:=<值> 临时覆盖（不算标定）。
改完 YAML 后 colcon build --symlink-install 或重启节点生效。

### 4.1 IMU 静态检查（决定 imu0_differential 与去重力）

命令：
    ros2 topic echo /imu/data --field linear_acceleration --once
    ros2 topic echo /imu/data --field angular_velocity

[ ] az ≈ ±9.81  ⇒ imu0_remove_gravitational_acceleration: true （驱动未去重力）
[ ] az ≈ 0      ⇒ 必须置 false，否则双重去重力污染 az
[ ] 静置 60 s，ω_z 漂移 < 0.5°/s ⇒ 保持 imu0_differential: false；漂移大 ⇒ 改 true

### 4.2 静态外参（双源参数，必须两处同时改，v2.1 R62）

[ ] 卷尺量 laser_link / imu_link / camera_link 相对 base_link 的 x y z + 安装角
[ ] RViz 复核 roll/pitch/yaw（看 /scan 与 /tf 是否歪斜）
[ ] 回填运行值：autocar_ws/src/autocar_bringup/launch/race.launch.py 里 extrinsics 的
    DeclareLaunchArgument 默认值
[ ] 回填记录值：autocar_ws/src/autocar_bringup/config/static_transforms.yaml 的 extrinsics: 三行
[ ] bash scripts/deploy.sh check 不再报 extrinsics.* FATAL

警告：只填一处 = FATAL。填了记录文件、忘了 launch，运行时 TF 仍是 identity，
      旧门禁会误报「已标定」。
警告：不要用命令行覆盖当标定手段（每次重敲 18 个数，漏一个就静默退化成 identity）。

### 4.3 舵机中位与满舵（Q5）

命令：
    ros2 topic pub --once /steering_angle std_msgs/msg/Float32 "{data: 0.0}"     # 中位
    ros2 topic pub --once /steering_angle std_msgs/msg/Float32 "{data: 0.45}"    # 右满舵
    ros2 topic pub --once /steering_angle std_msgs/msg/Float32 "{data: -0.45}"   # 左满舵

[ ] 中位时车轮正对前进方向 ⇒ 否则调 servo.neutral_pwm（每次 ±10 µs）
[ ] 角度尺量满舵实际转角 ⇒ 回填 max_steering_angle（占位 0.45 rad）
[ ] 无尖叫/撞限位 ⇒ 否则减小 servo.max_pwm_delta

### 4.4 阿克曼轴距（Q4）

[ ] 量前轴中心到后轴中心水平距离 L
[ ] 回填三处一致：planning.yaml / control.yaml / chassis_common.yaml
[ ] path.min_turning_radius 留 0.0（由 L / tan(max_steering_angle) 现算）
